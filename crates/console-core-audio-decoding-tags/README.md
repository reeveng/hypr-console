# Console audio tags

The tag readers of Project Symphonia's `symphonia-metadata`: ID3v2, FLAC and
Vorbis comments, RIFF INFO chunks and the iTunes free-form names, with the ID3v1
genre list that MPEG-4 files still index. ID3v1 itself, ID3v2 restriction
parsing and the other upstream surface nothing here reads are omitted.

Symphonia's source is offered under the Mozilla Public License 2.0, which
`LICENSE` carries. The rewritten readers keep that notice.
