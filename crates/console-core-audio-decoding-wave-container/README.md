# Symphonia RIFF (AIFF, WAVE) Demuxer

AIFF and WAVE demuxer for Project Symphonia, carried here without its feature flags: both containers are always built.

**Note:** This crate is part of Symphonia. Please use the [`symphonia`](https://crates.io/crates/symphonia) crate instead of this one directly.
